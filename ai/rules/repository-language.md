# Repository language

All human-readable content in repository files must be written in English. This applies to:

- Documentation, README files, AI rules, role instructions, and saved prompts.
- Source code comments, identifiers, file names, and directory names.
- UI copy, SEO metadata, accessibility labels, and image descriptions.
- Test descriptions, fixtures, log messages, error messages, and configuration examples.

Write new content in English and translate non-English prose when editing existing files. Preserve facts, behavior, proper names, URLs, and technical values while translating.

This rule governs repository files. Conversation with the user follows the language of their request unless they ask otherwise.
