# Repository instructions

Read and follow [the repository language rule](ai/rules/repository-language.md) for every task.

Role instructions and shared project context are in [ai/roles](ai/roles/README.md). Use the role relevant to the current task and follow the user's latest instructions.

When present, read `ai/roles/.00-context.local.md` for local working context. This optional file is excluded from Git; keep its contents out of tracked files, generated site assets, and external messages unless the user explicitly authorizes sharing them. Public documentation and routine project work must remain usable without it.
